# Киновечер — заметки для работы над проектом

Сайт «смотрим вместе»: ведущий показывает экран, друзья смотрят, рядом общий чат. Деплой — Vercel (страницы + функция `api/token.js`), видео и чат — LiveKit Cloud. Подробности и инструкция деплоя — в README.md.

## Команды
- `npm start` — локально на http://127.0.0.1:3737; нужен `.env` с `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`. У владельца порт 3000 занят чужим проектом, а `localhost` на Windows может вести на него — поэтому порт 3737 и адрес цифрами.
- `npm test` — тесты сервера (node:test, без сети: LiveKit подменяется заглушкой).
- Сквозной тест: `npm install --no-save playwright-core`, затем с переменными LiveKit `npm run test:browser`, потом `npm prune`. Локальный LiveKit: `livekit-server --dev --bind 127.0.0.1 --node-ip 127.0.0.1` (ключи `devkey` / `secret`, адрес `ws://127.0.0.1:7880`); бинарника в проекте нет — его скачивали во временную папку с согласия владельца.

## Устройство
- `server/token.js` — пропуск (JWT HS256, без библиотек): только своя комната, `canPublishSources: screen_share, screen_share_audio`, `canUpdateOwnMetadata` (смена имени и отметка «смотрит»). Подсчёт участников для «комната заполнена» — через Twirp `ListParticipants` с коротким админским пропуском; при сбое пускаем.
- `api/token.js` — функция Vercel, `server/app.js` — то же для локального сервера.
- `public/js/live.js` — вся работа с LiveKit: ведущий = тот, кто публикует `ScreenShare`; при одновременном старте экран остаётся у меньшего id. Чат — data-сообщения (`chat`); история — новичок шлёт `chat-history-request`, отвечают все, у кого она есть, новичок 1,5 с собирает и сортирует. У сообщения, пришедшего раньше, чем стал известен участник, `participant` = undefined — id брать из последнего аргумента `DataReceived`.
- `public/js/room.js` — интерфейс. У ведущего на сцене большая копия показа (звук в копии выключен), настройки — во всплывающей панели; при показе всего экрана копия скрыта.
- `public/vendor/livekit-client.js` — побайтная копия `dist/livekit-client.esm.mjs` 2.25.0 без строки sourceMappingURL. Обновлять так же (через Node, не через grep/sed — Git Bash портит переводы строк).

## Правила
- Зависимостей нет (папка в OneDrive). Новые пакеты без причины не добавлять.
- Строгая CSP: никаких inline-скриптов, `<style>` и атрибутов `style`; стили из JS — только `el.style.…`. CSP в `vercel.json` должна совпадать с `buildCsp()` из `server/app.js` (с `*.livekit.cloud`) — это проверяет тест.
- Интерфейс и сообщения — на русском. Тексты вставлять через `textContent`/`el()`, не через `innerHTML`.
- У страницы комнаты не должно быть `overflow: hidden` на `body`: телефон на боку тогда обрезает лишнее без прокрутки. В ландшафте на телефоне сцена и чат стоят рядом.
- Вёрстку на телефоне проверять по `getBoundingClientRect()` блоков и настоящей прокруткой колесом (`scrollInfo`/`assertFits` в `test-e2e/browser.mjs`): `scrollWidth` и `scrollTo()` из скрипта врут при `overflow: hidden`.
- Реальный выбор экрана и системный звук автоматикой не проверить — только руками.
