# Киновечер

Сайт для совместного просмотра: один участник показывает экран (YouTube, Google, любой плеер — что видно на экране, то и передаётся), остальные видят и слышат его, а рядом идёт общий чат. Без регистрации, комната создаётся по ссылке.

## Как это устроено

```
Ведущий (Chrome/Edge) ── экран и звук, один поток ──▶ LiveKit Cloud ──▶ каждый зритель
                                                        (и чат тоже)
Vercel: страницы (public/) + функция api/token.js, которая выдаёт «пропуск» в комнату
```

- **Vercel** раздаёт страницы и выдаёт пропуска. Сам видеопоток через Vercel не идёт.
- **LiveKit Cloud** — сервер видео и чата. Ведущий отправляет поток **один раз**, а LiveKit раздаёт его всем зрителям. Он сам пробивается через мобильный интернет, корпоративные сети и роутеры, поэтому у друзей работает «из коробки».
- Секрет LiveKit хранится только в настройках Vercel. В браузер попадает лишь подписанный пропуск в одну комнату, который разрешает смотреть, писать в чат и показывать экран (камера и микрофон запрещены).

## Выложить на Vercel

Нужны два бесплатных аккаунта: LiveKit Cloud и Vercel. Карта не нужна.

### 1. LiveKit Cloud — сервер видео

1. Зарегистрируйся на <https://cloud.livekit.io> и создай проект (имя любое).
2. В настройках проекта открой раздел с ключами (Settings → Keys / API keys) и создай ключ.
3. Сохрани три значения:
   - **адрес проекта** вида `wss://имя-проекта.livekit.cloud`;
   - **API Key**;
   - **API Secret** — его показывают один раз, сразу скопируй.

### 2. Vercel — сам сайт

**Вариант А, через GitHub (удобнее всего):**

1. Загрузи папку проекта в репозиторий GitHub. Файл `.env` с ключами туда не попадёт, он в `.gitignore`.
2. На <https://vercel.com> нажми **Add New → Project** и импортируй репозиторий.
3. **Framework Preset: Other**. Остальное не трогай: `vercel.json` уже говорит, что страницы лежат в `public/`.
4. В **Environment Variables** добавь три переменные:

   | Имя | Значение |
   |---|---|
   | `LIVEKIT_URL` | адрес проекта `wss://….livekit.cloud` |
   | `LIVEKIT_API_KEY` | API Key |
   | `LIVEKIT_API_SECRET` | API Secret |

5. Нажми **Deploy**.

**Вариант Б, из командной строки:**

```powershell
npm install -g vercel
cd "C:\Users\rusla\OneDrive\Desktop\фильмы"
vercel
```

`vercel` спросит про вход и проект; на остальные вопросы подходят ответы по умолчанию. Потом добавь переменные (значение он спросит сам) и выложи окончательную версию:

```powershell
vercel env add LIVEKIT_URL production
vercel env add LIVEKIT_API_KEY production
vercel env add LIVEKIT_API_SECRET production
vercel --prod
```

> Переменные окружения действуют только на **новые** деплои. Если добавил их после первого деплоя, нажми в Vercel **Redeploy** (или снова запусти `vercel --prod`).

### 3. Проверка

Открой свой адрес вида `https://имя.vercel.app` → «Создать комнату» → «Пригласить» → отправь ссылку друзьям.

Если вместо комнаты видно «Сайт ещё не настроен», значит не заданы переменные `LIVEKIT_…` или после их добавления не было Redeploy.

## Лимиты бесплатных тарифов

- **LiveKit Cloud, тариф Build ($0):** 50 ГБ исходящего трафика и 5 000 минут участников в месяц, до 100 подключений одновременно (сверено 24.11.2026 на livekit.com/pricing — условия могут поменяться). Час фильма в 1080p — около 2 ГБ на каждого зрителя. На четверых друзей это примерно 3 двухчасовых фильма в месяц в 1080p или около 6 в 720p (качество выбирается в «Настройках показа»). На бесплатном тарифе это жёсткий потолок: когда он кончится, комнаты не будут работать до следующего месяца. Дальше — платный тариф (от $50/мес, 250 ГБ) или свой сервер LiveKit.
- **Vercel Hobby:** бесплатно для личного некоммерческого использования. Функция вызывается один раз при входе в комнату, так что нагрузки почти нет.

## Что важно знать

| | |
|---|---|
| **Кто может показывать** | Только компьютер, лучше Chrome или Edge. С телефона можно только смотреть. |
| **Звук** | Chrome и Edge передают звук **вкладки** (выбери вкладку с видео и оставь галочку звука) или **всей системы** (для «Весь экран» включи галочку системного звука). Отдельное окно приложения передаётся без звука. Firefox и Safari звук экрана не передают. |
| **Сервисы с DRM** | Netflix, Disney+, Prime Video и подобные при показе экрана могут быть чёрными — это защита браузера и системы, сайт её обойти не может. YouTube, Google Drive, Twitch, VK Видео, локальные плееры работают. |
| **Интернет ведущего** | Нужен один поток наружу: «1080p · хороший» ≈ 4,5 Мбит/с, «720p · экономный» ≈ 2 Мбит/с — сколько бы ни было зрителей. Если не хватает, ведущий увидит жёлтую точку на «Настройках показа». |
| **Сколько человек** | До 8 в комнате (меняется переменной `MAX_PEERS_PER_ROOM`). |
| **Чат** | Опоздавшие получают последние 100 сообщений от тех, кто уже в комнате. На сервере чат не хранится. |

**Если у ведущего рябит или пропадает картинка:** по умолчанию используется кодек H.264 (его кодирует видеокарта). Открой комнату с `?codec=vp8` в конце адреса, например `/r/abcd-efgh?codec=vp8`.

## Запуск на своём компьютере

1. Скопируй `.env.example` в `.env` и впиши те же три значения LiveKit.
2. Запусти:

   ```powershell
   cd "C:\Users\rusla\OneDrive\Desktop\фильмы"
   npm start
   ```

3. Открой <http://127.0.0.1:3737>.

Друзья по адресу `127.0.0.1` не зайдут, сайт сам об этом предупредит. Для друзей используй адрес на Vercel.

## Структура

- `public/` — страницы, стили и скрипты. Их раздаёт Vercel.
  - `public/js/live.js` — вся работа с LiveKit: участники, показ экрана, чат и его история.
  - `public/js/room.js` — интерфейс комнаты.
  - `public/vendor/livekit-client.js` — библиотека LiveKit 2.25.0 (лицензия Apache-2.0, рядом её текст). Лежит в проекте, потому что защита страниц (CSP) не разрешает чужие скрипты.
- `api/token.js` — функция Vercel, которая выдаёт пропуск.
- `server/token.js` — общий код пропусков (используют и Vercel, и локальный сервер).
- `server/app.js`, `server/index.js` — локальный сервер для `npm start`.
- `vercel.json` — где лежат страницы, ссылки `/r/код` и заголовки безопасности.

## Тесты

```powershell
npm test
```

Это тесты сервера: пропуска, функция Vercel, `vercel.json`, локальный сервер. Сеть и LiveKit для них не нужны.

Сквозной тест в настоящем браузере проходит весь путь: двое-трое участников, показ экрана со звуком, чат и его история, обрыв связи, телефон в разных ориентациях, ошибки настройки. Ему нужен сервер LiveKit — локальный (`livekit-server --dev`) или свой проект в облаке:

```powershell
npm install --no-save playwright-core
$env:LIVEKIT_URL='ws://127.0.0.1:7880'; $env:LIVEKIT_API_KEY='devkey'; $env:LIVEKIT_API_SECRET='secret'; npm run test:browser
npm prune
```

Показ экрана в нём подменён движущейся картинкой, потому что системное окно выбора экрана автоматически не нажать. Поэтому **реальный выбор экрана и системный звук нужно проверять руками**.
